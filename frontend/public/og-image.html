Generate og-image.png

  1. Open this file directly in Chrome / Edge: frontend/public/og-image.html (just double-click).
  2. Press F12 → run Ctrl + Shift + P → type "Capture node screenshot" → in the Elements tab, right-click the <div class="canvas"> element → Capture node screenshot.
  3. Save the downloaded PNG as frontend/public/og-image.png (replace any existing file).
  4. Update frontend/index.html: change the two og:image / twitter:image URLs from og-image.svg back to og-image.png.
  5. Delete this file (og-image.html) — it's only a build artefact.
